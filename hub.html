What is actually hard about it

Payroll cannot be eventually consistent. A timekeeping bug is not a wrong pixel, it is somebody underpaid, so corrections are a reviewed workflow with an audit trail rather than an edit.

What is actually hard about it

Every client has to agree on one board. Socket.IO carries the round, the server owns the clock, and a player who closes the tab keeps their seat for ten minutes so a reconnect is not a forfeit.

An empty lobby kills a multiplayer game. Bots are seeded by ELO tier and play on an entropy schedule so a first-time player gets a real match at 3am; they are not flagged in-game, and they are excluded from every number on this screen.

Counting people is harder than counting rows. The live headcount ignores seats held for reconnects and the bots sitting in them, because a held seat is not a person in the room.

What is actually hard about it

Which sources are allowed is a decision, not a capability. Sources are chosen by what each site's robots.txt permits. Jobstreet disallows the endpoints that would be easiest to read, so that one arrives by email instead. Reachable is not the same as allowed.

It is split across two machines for one reason. One board answers a datacenter IP with a 403, so that reader runs on the laptop at home and hands batches to the droplet over a single pinned SSH command. Renting residential proxies would have solved it by impersonating somebody's home connection, which is not a trade I wanted.

Only one copy of the database is real. The core owns it; the worker keeps an integrity-checked daily copy and never writes.
