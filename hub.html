jobsift

A self-hosted job pipeline: sources in, filters and an LLM scoring pass in the middle, a spreadsheet and a Telegram message out. It is how I find the postings I actually apply to.

What is actually hard about it

Which sources are allowed is a decision, not a capability. Sources are chosen by what each site's robots.txt permits. Jobstreet disallows the endpoints that would be easiest to read, so that one arrives by email instead. Reachable is not the same as allowed.

It is split across two machines for one reason. One board answers a datacenter IP with a 403, so that reader runs on the laptop at home and hands batches to the droplet over a single pinned SSH command. Renting residential proxies would have solved it by impersonating somebody's home connection, which is not a trade I wanted.

Only one copy of the database is real. The core owns it; the worker keeps an integrity-checked daily copy and never writes.

What is actually hard about it

The assistant reaches nothing. No database, no filesystem, no network beyond the one call to the model. The worst case of a visitor talking it past every rule in its prompt is a wrong sentence on a portfolio. Give it a tool and the worst case becomes a reached system.

The deploy names what is public. Vercel served the repository root once, which meant it served the repository - the knowledge corpus, the system prompt and the guard thresholds were all downloadable. The build now copies an allowlist into dist, so a new file is public because somebody added it to that list.

A skill without provenance does not go on the list. The marquee it replaced claimed four technologies that no repository could show.
