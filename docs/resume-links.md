# Per-application resume links

Which tailored resume went to which employer. Kept here rather than in `r/` because
`scripts/build.mjs` serves only what its `PUBLIC` list names, and `docs/` is not on it,
so this file is never published.

Some boards accept no attachment — onlinejobs.ph has no file upload at all, and its own
guide tells applicants to link from Drive, OneDrive or Dropbox. On those, the link *is*
the resume delivery, so it has to point at the tailored variant rather than the general
master at `/Kim_Julongbayan_Resume.pdf`.

Filenames carry a random suffix so an employer holding one link cannot guess another and
find out where else you applied. `/r/*` is `noindex, nofollow` in `vercel.json`.

**These files are permanent.** An employer may open the link months after applying, and
deleting or renaming one 404s it for everyone who saved it. Never remove a variant a sent
letter points at.
